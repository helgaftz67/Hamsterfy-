Hamsterfy: поиск YouTube и SoundCloud

1. Распакуйте архив целиком в отдельную папку.
2. Закройте старый сервер и старую панель сервера Hamsterfy: они занимают порт 8765.
3. Запустите Start-Server.cmd. Окно сервера должно оставаться открытым.
4. В приложении Hamsterfy откройте настройки своего сервера и укажите адрес,
   который напечатан в окне запуска: http://АДРЕС-КОМПЬЮТЕРА:8765.
   На этом же компьютере можно использовать http://localhost:8765.
5. Ищите исполнителя и песню в приложении. Теперь сервер ищет по папке с музыкой,
   Audius, Archive, YouTube и SoundCloud. Если одна запись недоступна, выберите другую.

Телефон и компьютер должны быть в одной домашней сети. Для подключения извне
нужен отдельно настроенный доступ к компьютеру. Сервер не предоставляет VPN.
Разрешение в брандмауэре, если Windows его запросит, нужно для доступа с телефона.

Прежний APK не изменён. Новые результаты используют тот же API и адреса потоков,
что и обычные треки. Совместимость проверена тестами клиента; реальный телефон
в этой проверке не использовался. Приложение старой версии может прерывать
особенно медленный поиск через 20 секунд; повторите запрос.

Вы можете использовать уже имеющуюся папку с музыкой через команду:
dartaotruntime.exe server.aot --music "D:\Music" --port 8765
Дополнительные параметры: --token ВАШ_КЛЮЧ и --cache-gb 20.
Если зададите ключ, тот же ключ нужно указать в приложении.

Что добавлено:
- Поиск названий и исполнителей через yt-dlp: до 20 результатов с YouTube
  и до 20 с SoundCloud на запрос, плюс прежние источники.
- Воспроизведение доступных полных аудиопотоков. Подписанные адреса получаются
  при запуске трека, а не сохраняются в поисковой выдаче навсегда.
- Прямое аудио передаётся через сервер с поддержкой Range/перемотки.
  HLS из SoundCloud открывается плеером непосредственно у источника.
- Альтернативные загрузки с одинаковым названием сохраняются отдельными строками.
- Отказ одного источника не убирает результаты остальных.
- Онлайн-треки этих двух источников не скачиваются в постоянную коллекцию.

Ограничения:
Ни один из источников не содержит всех существующих песен. Возможны каверы,
ремиксы, удаления, региональные ограничения и запрос входа со стороны сервиса.
Найденное название не гарантирует, что запись будет воспроизводиться.
Платные записи и DRM не открываются этой доработкой.
На проверявшемся подключении YouTube искал записи, но при получении звука
потребовал подтверждение входа. Через SoundCloud успешно получен настоящий
аудиофрагмент «Rammstein — Sonne» (не только сведения о записи).
По запросам «Rammstein Sonne» и «Григорий Лепс Рюмка водки» оба источника
вернули результаты. Наличие названия не подтверждает правильность каждой версии.

Новая отдельная Windows-панель и новый APK не собирались. Старую панель
не запускайте вместо Start-Server.cmd: в ней встроена старая версия сервера.

Состав:
server.aot — скомпилированная программа Hamsterfy;
dartaotruntime.exe — официальный runtime Dart 3.14.1;
tools/yt-dlp.exe — официальный yt-dlp;
tools/deno.exe — официальный Deno для JavaScript-задач yt-dlp.
Устанавливать Dart, Python или ffmpeg для этого сервера не требуется.

Исходники приложены отдельным архивом Hamsterfy-modified-source.zip.
